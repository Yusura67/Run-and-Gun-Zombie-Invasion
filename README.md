# 🎮 [Run & Gun Zombie Invation]
## 📖 ภาพรวม (Overview)
เนื้อเรื่องย่อ : ณ วิทยาลัยเทคนิคจันทบุรี ธณพัชร สุขเลิศ ชื่อเล่น น็อต นักศึกษาชั้นปีสุดท้าย ต้องเผชิญกับเหตุการณ์ไม่คาดฝันเมื่อไวรัสฮันตา เกิดการกลายพันธุ์ครั้งใหญ่และแพร่ระบาดอย่างรวดเร็วโดยที่รัฐบาลรับมือไม่ทัน ทำให้นักศึกษาและผู้คนจำนวนมาก ทั่วทั้งทวีป รวมถึงประเทศไทย กลายเป็นซอมบี้
ในระหว่างการหนีตายขึ้นไปยังดาดฟ้าของตึกอำนวยการ กฤษฎา ชายชม เพื่อนรักของน็อต พลาดท่าถูกฝูงซอมบี้รุมกัดจนติดเชื้อต่อหน้าต่อตา ด้วยความโศกเศร้าและสูญเสีย น็อตหนีเอาชีวิตรอดลงจากตึก และมุ่งหน้าไปยังห้องใต้ดินของตึกอิเล็กทรอนิกส์ ที่นั่นเขาได้สัมผัสกับขุมพลังงานลึกลับบางอย่างที่เปลี่ยนให้เขาก้าวข้ามความเป็นมนุษย์ ก้าวข้ามไปสู่พระเจ้า God Not ความแค้นที่เสียเพื่อนรักไปทำให้เขาถูกครอบงำด้วยความมืดมิด เขาตัดสินใจกวาดล้างมนุษยชาติเพื่อล้างแค้นให้กับโลกที่โหดร้าย โดยนำร่างของกฤษฎา เปลี่ยนให้กลายเป็นราชาจอมปีศาจ Demon King เพื่อเป็นแม่ทัพคอยควบคุมและขยายพันธุ์ฝูงผู้ติดเชื้อ เพื่อกวาดล้างมนุษยชาติให้สิ้นซาก
ตัวละครหลัก (Characters):
ผู้เล่น : เป็นทหารหน่วยรบพิเศษที่ถูกส่งตัวเข้ามายังเขตแดนของปีศาจ เป้าหมายหลักคือการบุกทะลวงฝูงซอมบี้เข้าไปสังหาร Demon King เพื่อตัดหัวหน้าขบวนการและหยุดการควบคุมฝูงซอมบี้ ทว่าภารกิจกลับนำไปสู่การเผชิญหน้ากับเหตุการณ์ที่เหนือธรรมชาติในท้ายที่สุด
กฤษฎา ชายชม (Demon King): อดีตนักศึกษาที่ถูกเปลี่ยนให้เป็นอาวุธสงครามชีวภาพร่างยักษ์ ถือดาบขนาดใหญ่ คอยเฝ้าลานประลองซากวิหาร
ธณพัชร สุขเลิศ (Not God - Final Boss): ตัวการใหญ่ที่อยู่เบื้องหลังความพินาศ ปรากฏตัวในรูปแบบของศีรษะขนาดยักษ์ดวงตาแดงก่ำ ผู้ซึ่งมีพลังไร้ขีดจำกัดจนอาวุธยุทโธปกรณ์ใดๆ ก็ไม่สามารถทำอันตรายได้ สิ่งเดียวที่หน่วยรบพิเศษทำได้คือ "วิ่งหนีเอาชีวิตรอด"
สถานที่ (Setting): วิทยาลัยเทคนิคจันทบุรีที่ถูกทิ้งร้างและบิดเบี้ยวด้วยพลังงานมืด สภาพแวดล้อมเต็มไปด้วยซากปรักหักพัง ก่อนจะเชื่อมต่อไปยังมิติที่เป็นลานประลองวิหารของ Demon King


**เทคโนโลยีที่ใช้ (Tech Stack):** 
โปรเจกต์นี้พัฒนาขึ้นด้วยภาษา C/C++ โดยมีการเรียกใช้ไลบรารีที่สำคัญ ได้แก่:
*   **[Raylib](https://www.raylib.com/):** ใช้สำหรับจัดการระบบกราฟิก (2D/3D), การแสดงผลหน้าจอ, ระบบเสียง และการรับค่า input จากผู้เล่น
*   **[ENet](http://enet.bespin.org/):** ใช้สำหรับจัดการระบบ Network และ Multiplayer ที่มีความเสถียรผ่านโปรโตคอล UDP

## 🚀 วิธีการติดตั้งและการเปิดเล่นเกม (Installation & How to Play)

### สิ่งที่ต้องมี (Prerequisites)
- C/C++ Compiler (เช่น GCC, Clang หรือ MSVC)
- เครื่องมือ Build (เช่น Makefile หรือ CMake)

### วิธีการติดตั้งและการเปิดเล่น (Installation & How to Play)
โปรเจกต์นี้มีเพียง Source Code ผู้เล่นจำเป็นต้องนำไปคอมไพล์เอง
1. โคลนโปรเจกต์นี้ลงในเครื่องของคุณ:
   `git clone https://github.com/Yusura67/Run-and-Gun-Zombie-Invasion.git`
2. เปิดโฟลเดอร์โปรเจกต์ด้วย IDE ที่รองรับ C/C++ (เช่น Visual Studio หรือ VS Code)
3. ตรวจสอบให้แน่ใจว่าได้ตั้งค่าการเชื่อมต่อไลบรารี Raylib และ ENet ไว้ในโปรแกรมของคุณแล้ว
4. ทำการ Compile และ Run ผ่านโปรแกรม IDE ของคุณ

### การควบคุม (Controls)
*   **(W) (A) (S) (D)** - เคลื่อนที่
*   **(Spacebar)** - กระโดด / ยืนยัน
*   **(Mouse)** - ควบคุมมุมมอง / โจมตี

## 🧠 ตรรกะสำคัญหรือระบบเด่นในเกม (Key Features)

*   **ระบบกราฟิกแบบ Custom:** ใช้ฟังก์ชันจาก `raylib.h` และ `rlgl.h` เพื่อจัดการการเรนเดอร์ภาพภายในเกมให้มีความลื่นไหล
*   **ระบบ Multiplayer ** รองรับการเชื่อมต่อและเล่นร่วมกันผ่านระบบเครือข่าย โดยใช้ไลบรารี `enet` ในการรับส่งแพ็กเก็ตข้อมูลระหว่าง Client และ Server อย่างมีประสิทธิภาพ สามารถเล่นโดยการเปิดผ่าน LAN ได้เลย แต่เป็นเพียง BATA อาจมีบัค
